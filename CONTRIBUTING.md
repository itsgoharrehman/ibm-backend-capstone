# Contributing Guidelines

This repository represents completed academic capstone coursework for the IBM Backend Development Professional Certificate program.

---

## Academic Integrity Policy

* **No Solution Alterations**: In observance of academic integrity and institutional honor codes, pull requests altering canonical capstone solutions or adding answers will be declined to prevent providing answers to actively enrolled students.
* **Permitted Contributions**: Contributions are strictly limited to documentation enhancements, dependency updates, and container configuration improvements.

---

## Code of Conduct

All contributors and participants must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

---

## Pull Request Guidelines

1. Confirm that changes preserve academic integrity and do not alter graded solutions.
2. Ensure no personal credentials, MongoDB Atlas connection strings, or private API keys are committed.
3. Open a Pull Request targeting the `main` branch and complete the academic checklist.
